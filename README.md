
# 🏨 Hotel Performance & Guest Insights Dashboard

## 🎯 Project Objective  
The primary objective of this project is to analyze hotel performance across multiple locations in Pakistan, focusing on revenue generation, customer ratings, booking trends, visitor demographics, and amenity usage. The dashboard provides valuable insights for hotel managers and stakeholders to make data-driven decisions to improve occupancy, pricing strategies, and customer satisfaction.

---

## 📊 Dataset Used  
📂 [Pakistan_Tourism_Hotels.csv](https://github.com/FatimaBatool55/Pakistan_Hotel_Project/blob/main/Pakistan_Tourism_Hotels.csv)  
The dataset contains information on 21 hotels, including:

| Category             | Attributes |
|----------------------|------------|
| 🏨 Hotel Details     | Name, City, Province, Coordinates, Year, Month |
| 📈 Performance Metrics | Occupancy %, Room Rate (PKR), Total Rooms, Rooms Booked, Total Revenue |
| 👥 Customer Insights | Customer Type, Rating, Visitor Type (Local/Foreign) |
| ⚙️ Operational Details | Booking Source, Staff Count, Amenities Count |

---

## ❓ Key Questions / KPIs Explored  

| KPI Area                     | Questions Answered |
|-----------------------------|--------------------|
| 💰 Revenue Analysis          | Which hotels generate the highest total revenue? |
| 🌍 Visitor Demographics      | What is the distribution of local vs. foreign visitors across cities? |
| ⭐ Customer Satisfaction     | Which provinces and hotels have the highest customer ratings? |
| 🛎️ Booking Behavior         | What are the most popular booking sources and customer types? |
| 🧺 Amenities Impact          | How do amenities correlate with total revenue trends? |

---

## 📌 Primary KPIs  

| KPI                          | Description |
|-----------------------------|-------------|
| 💰 Total Revenue             | Overall & by hotel |
| 👥 Total Visitors            | Local vs. Foreign |
| ⭐ Average Customer Rating   | By hotel and province |
| 🛎️ Revenue by Booking Source | Booking.com, Travel Agencies, etc. |
| 🧺 Revenue by Amenities Count| Correlation with hotel facilities |

---

## ⚙️ Process  

- **🧹 Data Preparation**  
  - Cleaned and standardized hotel names and attributes  
  - Ensured numeric columns were correctly formatted for aggregation  
  - Created calculated measures for KPIs such as total visitors and revenue breakdowns  

- **🔗 Data Modeling**  
  - Structured relationships between hotel details, booking info, and customer insights  
  - Used DAX measures for dynamic calculations  

- **📊 Dashboard Creation in Power BI**  
  - Designed interactive visuals for each KPI  
  - Added slicers for hotel name and location filtering  
  - Applied consistent theme and layout for readability
